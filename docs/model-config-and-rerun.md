# Model config + ingestion rerun

_Summary of the `dev` branch changes for this pass. All work landed on `dev`, then merged to `main` locally. Nothing pushed._

## 1. What changed

### LLM providers — model per role
Nodes still ask `provider_registry.get_model(model_id)` for a model by name.
Routing is the only change: GMI MiniMax ids now go to GMI Cloud; everything
else stays on OpenRouter.

| Role | Model | Provider | Why |
|------|-------|----------|-----|
| Routing agent (`ROUTER_MODEL`) | `MiniMaxAI/MiniMax-M2.7` | GMI Cloud (free) | Heavy reasoning; free tier |
| Source / table summaries (`manifest._describe`) | `openai/gpt-4o-mini` | OpenRouter | Bulk, cheap, runs per doc at ingest |
| SQL drafting (`db_node.generate_sql`) | `openai/gpt-4o-mini` | OpenRouter | Light, retried up to 3x |
| Embeddings (`embedder`) | `openai/text-embedding-3-large` | OpenRouter | Unchanged; 3072-dim |

- Only the two **free** GMI models are allowed: `MiniMaxAI/MiniMax-M2.7`
  and `MiniMaxAI/MiniMax-M3` (set `GMI_MODELS` in `provider_registry.py`).
- GMI Cloud is an OpenAI-compatible endpoint, so it routes through
  `langchain-openai` (new dependency) with `base_url = GMI_BASE_URL`.
- `.env` keys: `GMI_API_KEY`, `GMI_BASE_URL`, `OPENROUTER_API_KEY`,
  `OPENROUTER_MODEL`, `ROUTER_MODEL`. See `backend/.env.example`.

### Config (`backend/app/core/config.py`)
- Added Qdrant block: `QDRANT_URL`, `QDRANT_API_KEY`, `QDRANT_HOST`,
  `QDRANT_PORT`, `QDRANT_COLLECTION`.
- Renamed `GMI_CLOUD_KEY/GMI_CLOUD_BASE_URL` -> `GMI_API_KEY/GMI_BASE_URL`
  (matches what was already in `.env`), gave `GMI_BASE_URL` a default.
- `ROUTER_MODEL` default is now the MiniMax id.

### Vector indexer (`backend/app/ingestion/vector_indexer.py`)
- `_build_client()`: uses `QDRANT_URL` (+ api key, 60s timeout) when set,
  else local `host:port`. Collection name comes from settings.

### Fixes picked up from `main`
- `doc_loader.py` had committed merge-conflict markers on `dev` — resolved
  to `main`'s clean `if __name__ == "__main__"` version.
- Merged `origin/main` into `dev` first so the later `dev -> main` merge
  was a fast-forward.

### Local `.env` gotcha
`CORS_ORIGINS=host,host` breaks pydantic-settings (expects JSON for a
`List[str]`). Commented it out in the local `.env`; the code default is
identical. `.env.example` documents the JSON form.
